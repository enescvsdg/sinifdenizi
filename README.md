# SınıfDenizi

SınıfDenizi, sınıf içi başarıyı oyunlaştıran akvaryum temalı bir eğitim prototipidir.

## V1 özellikleri
- Öğretmen ve veli girişi
- Öğrenci profilleri ve profil fotoğrafı desteği
- Görev, XP, yem ve rozet sistemi
- Sınıf başarısına göre gelişen dekorasyonlar
- Geniş ve tam ekran akvaryum
- Balıkların serbest yüzme mekaniği
- Veli için salt-okunur gelişim ekranı
- Responsive web arayüzü

## Çalıştırma
Statik bir web uygulamasıdır. `index.html` dosyasını açabilir veya yerelde:

```bash
python3 -m http.server 8080
```

komutunu çalıştırıp `http://localhost:8080` adresine gidebilirsiniz.

> V1 demo prototipidir. Üretim sürümünde gerçek kimlik doğrulama, Supabase/PostgreSQL, dosya depolama ve yetkilendirme politikaları eklenmelidir.
